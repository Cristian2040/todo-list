# Todo List App

Una aplicación web moderna y minimalista para gestionar tus tareas diarias. Desarrollada con HTML5, CSS3 y JavaScript (Vanilla).

## Características

- **Gestión de Tareas**: Agregar, marcar como completadas y eliminar tareas.
- **Persistencia de Datos**: Las tareas se guardan automáticamente en el navegador (`localStorage`).
- **Filtros**: Visualiza todas las tareas, solo las pendientes o las completadas.
- **Contador**: Muestra cuántas tareas pendientes quedan.
- **Diseño Responsive**: Funciona perfectamente en móviles y escritorio.
- **Modo Oscuro**: Interfaz agradable a la vista con colores modernos.

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica.
- **CSS3**: Variables, Flexbox, animaciones y diseño responsive.
- **JavaScript**: Lógica del DOM, manejo de eventos y almacenamiento local.

## Instalación y Uso

1. **Clonar el repositorio** (o descargar los archivos):
   ```bash
   git clone https://github.com/tu-usuario/todo-list.git
   ```
2. **Abrir el proyecto**:
   Navega a la carpeta del proyecto y abre el archivo `index.html` en tu navegador favorito.
